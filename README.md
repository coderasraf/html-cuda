# Cuda - Single-Page HTML Template

A responsive single-page agency template ("Cuda") built with HTML, CSS, Bootstrap, and jQuery, with sections for services, team, skills, portfolio, and testimonials.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![Bootstrap](https://img.shields.io/badge/Bootstrap-4-7952B3?logo=bootstrap&logoColor=white) ![jQuery](https://img.shields.io/badge/jQuery-0769AD?logo=jquery&logoColor=white)

## Overview

An early front-end practice project from 2020: a PSD-to-HTML style conversion of the "Cuda" one-page template for a web design and app development agency. Copy is mostly placeholder text.

## Features

- Hero section ("We build awesome websites and mobile apps") with call to action
- Off-canvas navigation menu with overlay
- Sticky section navigation using jQuery Waypoints
- Services grid
- Team section with member cards
- "We got skills!" section with animated SVG radial progress charts that start on scroll
- Portfolio grid with category filtering powered by Isotope
- Testimonials section
- Animate.css and a dedicated responsive stylesheet

## Tech Stack

- HTML5, CSS3
- Bootstrap 4
- jQuery, Isotope, Waypoints, radial progress bar script
- Animate.css, Font Awesome

## Getting Started

No build step is required.

```bash
git clone https://github.com/coderasraf/html-cuda.git
cd html-cuda
```

Open `index.html` in your browser, or use a static server such as the VS Code Live Server extension.
